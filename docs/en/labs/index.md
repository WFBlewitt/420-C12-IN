# Lab Schedule

This section contains the course's practical activities. Each Lab accompanies a Session and applies its concepts.

| Lab | Topic | Main outcome |
|---:|---|---|
| [1](lab-1.md) | Exploring the workstation | Descriptive record |
| [2](lab-2.md) | Representing values in bases 2, 10, and 16 | Conversion and checks |
| [3](lab-3.md) | Interpreting internal representations | Encoding and byte order |
| [4](lab-4.md) | Locating and moving data | Physical layers and memory trace |
| [5](lab-5.md) | Observing the processor | Inventory and fixed-width arithmetic |
| [6](lab-6.md) | Evaluating RAM | Inventory, calculations, compatibility |
| [7](lab-7.md) | Observing boot and firmware | Diagnosis and recovery requirements |
| [8](lab-8.md) | Designing a compatible platform | Selection and recommendation |
| [9](lab-9.md) | Evaluating storage | Calculations, RAID, protection |
| [10](lab-10.md) | Observing resources and file systems | Commands and OS comparison |
| [11](lab-11.md) | Evaluating graphics and audio | Observation, calculation, diagnosis |
| [12](lab-12.md) | Troubleshooting a peripheral chain | Connectors, USB, drivers, accessibility |
| [13](lab-13.md) | Comparing integrated and modular platforms | Cost, replacement cycle, recommendation |
| [14](lab-14.md) | Observing and diagnosing two network exchanges | Configuration, DNS, route, diagnosis |
| [15](lab-15.md) | Completing and verifying a PowerShell report | Guided script, CSV, JSON, validation |

## Lab rule

When a Lab requests a method, observation, or justification, that work forms part of the answer. A final result without explanation is not sufficient.
