# Technical Vocabulary

This page will serve as the cumulative glossary.

| Term | Short definition | Example or note |
|---|---|---|
| Computer | A programmable machine that processes information. | A laptop, smartphone, or server can be a computer. |
| Component | A hardware or software element of a system. | Processor, memory, operating system. |
| Peripheral | A device connected to a computer for input, output, or a specialized function. | Keyboard, monitor, printer, network adapter. |
