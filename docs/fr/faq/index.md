# Foire aux questions

Cette page rassemble les réponses détaillées aux questions qui demandent une explication, une vérification technique ou une recherche supplémentaire.

Les questions publiées ici sont reformulées au besoin et ne permettent pas d'identifier la personne qui les a posées. La personne à l'origine de la question reçoit un message lorsque la réponse est disponible. Les mises à jour importantes sont également signalées dans Teams.

Le contenu de cette page évolue pendant le cours et sert d'outil d'apprentissage et de référence.
