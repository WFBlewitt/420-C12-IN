# Guide de qualite des sources

## Sources generalement solides

- documentation du fabricant;
- fiches techniques;
- manuels;
- documentation officielle;
- tests techniques detailles avec methode claire.

## Sources a utiliser avec prudence

- forums sans verification;
- videos sans sources;
- pages promotionnelles;
- reponses generees automatiquement;
- comparateurs sans explication de methode.

## Questions a poser

1. Qui publie l'information?
2. La date est-elle pertinente?
3. La source donne-t-elle des preuves?
4. L'information correspond-elle a d'autres sources fiables?
5. La source essaie-t-elle surtout de vendre quelque chose?
