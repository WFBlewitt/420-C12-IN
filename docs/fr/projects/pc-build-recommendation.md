# Projet de recommandation PC

## But

Recommander une configuration d'ordinateur selon les besoins d'un client et un budget realiste.

## A definir

- scenario client;
- budget;
- format de remise;
- composants obligatoires;
- exigences de compatibilite;
- grille d'evaluation.

## Question centrale

La configuration proposee repond-elle aux besoins du client de facon compatible, justifiee et realiste?
