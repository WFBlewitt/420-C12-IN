# Projets

Les projets servent a demontrer la capacite d'evaluer des composants logiciels et materiels.

| Projet | But | Statut |
|---|---|---|
| Recherche materielle | Explorer et decrire techniquement un composant materiel. | A definir |
| Recommandation PC | Proposer une configuration selon les besoins d'un client. | A definir |

## Competences communes aux projets

- comprendre le besoin;
- choisir des sources fiables;
- comparer des caracteristiques;
- justifier les recommandations;
- communiquer clairement.
