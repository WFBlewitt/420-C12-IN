# Vocabulaire technique

Cette page servira de glossaire cumulatif.

| Terme | Definition courte | Exemple ou remarque |
|---|---|---|
| Ordinateur | Machine programmable qui traite de l'information. | Un portable, un telephone intelligent ou un serveur peuvent etre des ordinateurs. |
| Composant | Element materiel ou logiciel d'un systeme. | Processeur, memoire, systeme d'exploitation. |
| Peripherique | Dispositif connecte a l'ordinateur pour l'entree, la sortie ou une fonction specialisee. | Clavier, ecran, imprimante, carte reseau. |

!!! tip "A completer"
    Ajouter les termes au fil des seances, avec une definition simple et une definition technique quand c'est utile.
