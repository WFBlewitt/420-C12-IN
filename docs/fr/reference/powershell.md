# PowerShell

## A venir

PowerShell sera utilise comme outil d'observation et d'automatisation.

Commandes de depart:

```powershell
Get-ComputerInfo
Get-PhysicalDisk
Get-NetAdapter
Get-Process
```

## Principe

PowerShell ne sert pas seulement a afficher du texte. Il manipule des objets que l'on peut filtrer, trier, selectionner et exporter.
